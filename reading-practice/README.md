# 京声朗读

北京高考英语听说机考“短文朗读”专项练习网页。

练习材料现按仿真篇幅设置：基础约150词、中等约160词、进阶约175—185词。点击录音按钮会同时启动90秒倒计时和浏览器语音识别，时间结束后自动停止录音、生成回放和朗读报告。报告将读对词标为绿色、疑似读错词标为红色、疑似漏读词保留黑色并添加波浪下划线。

自动识别属于练习辅助功能，结果会受到设备、网络、口音和环境噪声影响，并非北京高考官方评分。iPad 请直接使用 Safari 打开 HTTPS 网页，并确保系统已启用 Siri 或听写；从主屏幕打开的网页 App 可能无法使用语音识别。

## 使用方法

直接双击 `index.html` 即可使用。语音示范依赖浏览器内置英文语音；录音功能如果在本地文件模式下被浏览器限制，请在本目录运行：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

上面的静态服务器可用于普通朗读、录音和 OCR，但不提供账号接口。需要在本地测试注册、登录和云同步时，请在项目根目录运行：

```powershell
npm install
npx netlify-cli@latest dev
```

然后使用 Netlify CLI 显示的网址访问，不要双击 `index.html`。

## 自定义文章与照片识别

点击题库上方的“添加自己的文章”，可以直接粘贴英文，也可以在手机上拍照或从相册选择图片。照片识别使用网页内置的 Tesseract.js 英文模型，不会把照片上传到第三方服务器。首次识别需要加载约 20 MB 的本地模型，可能需要几秒到几十秒。

由于浏览器会限制本地文件启动 Web Worker，照片识别请优先按上面的命令通过 `http://localhost:8000` 使用；直接双击 `index.html` 时，录音、OCR 和浏览器内置翻译可能被浏览器安全策略拦截。

## 材料标注

- “真题主题仿写”：依据公开考生回忆中出现的真题主题重新编写，并非官方原文。
- “原创模拟”：按照北京高考短文朗读题型、篇幅和难度编写。

每篇内置材料均配有三个回答问题和参考答案。点击“开始回答问题”后，系统逐题播放问题，每题提供 40 秒录音时间，并根据浏览器语音识别文本与参考答案要点给出 0–2 分练习估分。自动结果不等同于北京教育考试院官方评分。

自定义文章也可以填写三组问题和参考答案；如需该功能，必须完整填写三组。问题、参考答案和回答练习成绩会随文章同步，原始录音仍只保存在当前浏览器。

## Netlify 账号与云端同步

部署完整项目后，网站支持用户名和密码登录，不需要邮箱或手机号。登录用户可以同步自定义文章和上次练习结果，也可以主动把私人文章提交给管理员审核。管理员只能查看主动投稿内容。

服务器功能不能通过单独双击 HTML 或只上传 `reading-practice` 文件夹启用。请将完整项目连接到 Netlify，并按照根目录的 `NETLIFY_DEPLOYMENT.md` 配置 `AUTH_SECRET` 和管理员用户 ID。

# 京声朗读

北京高考英语听说机考“短文朗读”专项练习网页。

练习材料现按仿真篇幅设置：基础约150词、中等约160词、进阶约175—185词。点击录音按钮会同时启动90秒倒计时和浏览器语音识别，时间结束后自动停止录音、生成回放和朗读报告。报告将读对词标为绿色、疑似读错词标为红色、疑似漏读词保留黑色并添加波浪下划线。

自动识别属于练习辅助功能，结果会受到设备、网络、口音和环境噪声影响，并非北京高考官方评分。iPad 请直接使用 Safari 打开 HTTPS 网页，并确保系统已启用 Siri 或听写；从主屏幕打开的网页 App 可能无法使用语音识别。

## 使用方法

直接双击 `index.html` 即可使用。语音示范依赖浏览器内置英文语音；录音功能如果在本地文件模式下被浏览器限制，请在本目录运行：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

上面的静态服务器可用于普通朗读、录音和 OCR，但不提供账号接口。需要在本地测试注册、登录和云同步时，请在项目根目录运行：

```powershell
npm install
npx netlify-cli@latest dev
```

然后使用 Netlify CLI 显示的网址访问，不要双击 `index.html`。

## 自定义文章与照片识别

点击题库上方的“添加自己的文章”，可以直接粘贴英文，也可以在手机上拍照或从相册选择图片。照片识别使用网页内置的 Tesseract.js 英文模型，不会把照片上传到第三方服务器。首次识别需要加载约 7 MB 的本地 OCR 核心与英文模型，网络较慢时可能需要一到两分钟；后续识别会使用浏览器缓存。

由于浏览器会限制本地文件启动 Web Worker，照片识别请优先按上面的命令通过 `http://localhost:8000` 使用；直接双击 `index.html` 时，录音、OCR 和浏览器内置翻译可能被浏览器安全策略拦截。

## 材料标注

- “真题主题仿写”：依据公开考生回忆中出现的真题主题重新编写，并非官方原文。
- “原创模拟”：按照北京高考短文朗读题型、篇幅和难度编写。
- “中考词汇”“高考词汇”：各25篇原创词汇朗读短文，每篇120–140个英文词，配22项目标单词或短语、语境中文释义及三组理解问题和参考答案。词汇为教学精选，不是官方完整考纲词表；保留正文中的实际词形，跨篇会复现。

词汇栏目可按英文单词、中文释义和主题搜索；打开文章后可展开“本篇核心词汇与短语”，点击英文听发音，朗读、录音、评分、收藏及生词标记沿用现有流程。数据保存在 `vocabulary-passages.js`。项目根目录运行 `node scripts/export-vocabulary-readings.mjs`，可生成便于后续教学使用的 `docs/北京中高考英语核心词汇朗读集.md`，含全部短文、词汇、理解问题和检索依据。

每篇内置材料均配有三个回答问题和参考答案。点击“开始回答问题”后，系统逐题播放问题，每题提供 40 秒录音时间，并根据浏览器语音识别文本与参考答案要点给出 0–2 分练习估分。自动结果不等同于北京教育考试院官方评分。

自定义文章也可以填写三组问题和参考答案；如需该功能，必须完整填写三组。问题、参考答案和回答练习成绩会随文章同步，问答录音仅用于当次回放，朗读录音按下方说明保存并同步。

## Netlify 账号与云端同步

部署完整项目后，网站支持用户名和密码登录，不需要邮箱或手机号。登录用户可以同步自定义文章和上次练习结果，也可以主动把私人文章提交给管理员审核。管理员只能查看主动投稿内容。

服务器功能不能通过单独双击 HTML 或只上传 `reading-practice` 文件夹启用。请将完整项目连接到 Netlify，并按照根目录的 `NETLIFY_DEPLOYMENT.md` 配置 `AUTH_SECRET` 和管理员用户 ID。

## 朗读录音保存

每篇文档保留最后一次朗读录音，使用 IndexedDB 保存在本机；登录后自动同步到账户，下次登录或换设备打开同一篇文档即可回放。未登录录音仅保存在当前浏览器。同步失败时保留本机副本，可在账户中点击同步重试。问答练习录音仍仅用于当次回放。

## 生词本复习

生词本将所有文章中标记的“不会读”和“不认识”的单词去重，按“新学、复习、已掌握”显示。列表默认只显示英文；点击单词后自动朗读并显示汉译，再选择“记得”或“不记得”。新学单词选择“记得”后移入复习，从0次开始累计；选择“不记得”则留在新学。复习单词连续3次选择“记得”后移入已掌握，中途选择“不记得”则清零连续次数，留在复习。每次作答后隐藏汉译，再次点击单词才能重新作答，重复点击同一个答案不会额外计数。已掌握单词仍可点击听读和查看汉译。

状态保存在本机，登录后随练习数据自动同步；不同设备按单词的最近更新时间合并。汉译优先使用本地词典，未收录时联网查询；查询失败时可再次点击重试，尚未显示汉译时不能提交记忆结果。
